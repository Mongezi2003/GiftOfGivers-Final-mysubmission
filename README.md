## Project Overview
This is a full-stack mobile application prototype for the Gift of the Givers foundation. It features a Kotlin-based Android client that securely authenticates users and retrieves data from a cloud-hosted ASP.NET Core REST API, backed by an Azure SQL Database.

## Technologies Used
- **Frontend:** Android (Kotlin, XML Layouts)
- **Backend:** ASP.NET Core Web API (C#)
- **Database:** Microsoft Azure SQL Database
- **Cloud Hosting:** Microsoft Azure App Service
- **Security:** SHA-256 Password Hashing

## How to Run Locally
1. **API:** Open the API solution in Visual Studio and run.
2. **Android App:** Open the Android app folder in Android Studio, connect an Android device via USB (with USB Debugging enabled), and click "Run".
